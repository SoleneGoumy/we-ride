# We Ride

A simple React Native app displaying wind conditions at the Serre-Ponçon wing foiling spot.

The app fetches wind data from the [OpenWindMap](https://openwindmap.org/) API and displays the current conditions in a simple mobile interface.

## Features

- Current wind conditions at Serre-Ponçon
- Wind speed and direction
- Simple mobile interface
- Data fetched from the OpenWindMap API

## Tech Stack

- React Native
- TypeScript
- OpenWindMap API

## Getting Started

### Install dependencies

```bash
npm install
```

Start the development server

```
npx expo start
```

Then open the app with Expo Go or an available emulator.

## About

We Ride was created as a small personal project to quickly check wind conditions before going wing foiling at Serre-Ponçon.
